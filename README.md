A camp reservation mobile application built with React Native, Expo, Node.js, Express, and PostgreSQL.

CampingApp is a project designed to simplify the process of discovering campsites, checking their details, and managing reservations. 
The application provides a mobile interface for users and a separate set of administrative features for managing camps, reservations, users, and rental equipment.

User features

    User authentication — registration, login, and logout.
    Campsite discovery — browse campsites and view their descriptions, prices, amenities, and images.
    Search and filtering — search campsites by name or description and filter by price and selected amenities.
    Interactive map — explore campsite locations on a map.
    Reservations — select check-in and check-out dates and calculate the total price.
    Equipment rental — view available equipment and include rentals in a reservation.
    Wishlist — save and remove favorite campsites.
    Reservation management — view reservation details and cancel eligible reservations.
    Profile management — view account information, log out, and deactivate an account.

Administrative features

    Create, update, and deactivate campsites.
    Manage campsite amenities, prices, locations, and images.
    Manage rental equipment and its availability.
    View and manage reservations.
    Manage user accounts, roles, and account activation.
    Restrict administrative operations according to user roles.
